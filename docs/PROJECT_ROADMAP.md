# 项目后续规划

## 1. 打通串口通信

让 ESP32 定期产生温度、湿度或设备状态数据，通过 UART 发送给 Linux 开发板。ARM 端用 termios 配置串口并读取数据。

## 2. 升级成 RS485 和 Modbus RTU

使用 USB 转 RS485 模块或者 MAX3485 模块：

- ESP32 作为 Modbus 从站；
- ARM Linux 网关作为主站；
- 支持最基础的 03 功能码，定期读取保持寄存器；
- 处理 CRC 校验、响应超时、非法帧和设备掉线。

不需要自己完整实现整个 Modbus 协议，可以先用 libmodbus 跑通，再决定是否手写最小协议解析。

## 3. 接入现有网关

增加一个设备采集模块：

- 从 Modbus 读取设备数据；
- 转换成你原来的 TLV 消息；
- 复用现有 Reactor 和 TCP 转发逻辑；
- 发送给 PC 上的订阅客户端。

这样原项目不需要推倒重来，只是多了一个真实的数据入口。

## 4. 补充板端运行能力

- 使用 CMake 交叉编译，而不是只在开发板上原生编译；
- 使用配置文件设置串口、波特率、从站地址和采集周期；
- 使用 systemd 开机启动；
- 串口掉线、从站超时、网络断开后自动恢复；
- 日志记录设备上线、超时、CRC 错误和重连。

MQTT 以后再加。
